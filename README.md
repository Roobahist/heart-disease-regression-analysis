# Heart Disease Regression Analysis

Reproducible statistical modelling of the [UCI-derived heart disease dataset](https://www.kaggle.com/datasets/johnsmith88/heart-disease-dataset), including logistic regression, stepwise selection, L1-regularized regression, diagnostics, and held-out evaluation.

> **Status:** Source and reproducible workflow are being assembled. Generated figures, metrics, and the compiled report are produced by the analysis workflow, not hand-entered.

**Collaborative university project:** David Yang, Arman Jahangiri, and Mojtaba Kanani Sarcheshmeh. Original team code: [davidhy8/heart-regression](https://github.com/davidhy8/heart-regression).

This is an educational retrospective analysis, **not** a clinically validated decision-support tool.
